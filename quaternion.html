四元数：为什么旋转要用 4 个数存 3 个自由度

欧拉角能表示任意朝向，但它有 万向节锁、插值会绕远路、而且有两个值对应同一个朝向。 四元数用 4 个数换来了统一的最短弧插值和没有奇点。 左边是三种插值方式的对比，右边是万向节的实体演示。

欧拉角线性插值（角度各自 lerp） 四元数 nlerp（先 lerp 再归一化） 四元数 slerp（球面最短弧）

左边：物体从起始朝向插值到目标朝向（yaw 150°、pitch 72°、roll −120°）， t 就是插值参数。黄色 = 起始，紫色 = 目标，中间是当前姿态。 右侧：三环万向节，把 pitch 拉到 ±90° 看会发生什么。

1. 三个数的病：万向节锁

  1. 欧拉角是三次连续旋转的复合（这里是 Y·X·Z）。中间的 pitch 转到 ±90° 时， 最外圈的轴和最内圈的轴方向重合，两个自由度塌缩成一个 —— 这就是万向节锁。
  2. 它不是"数值 bug"，是这种表示法本身的拓扑限制：欧拉角要覆盖 SO(3) 就得有奇点， 就像用经纬度表示球面必须在两极退化一样。
  3. 另一个病：(yaw, pitch, roll) 和 (yaw±180°, 180°−pitch, roll±180°) 是同一个朝向， 所以两个朝向之间"插值"时，直接 lerp 三个角度可能绕一大圈。

2. 四元数怎么来的

q = (axis · sin(θ/2), cos(θ/2))     // 绕 axis 转 θ
q 旋转向量：v' = q v q⁻¹            // q⁻¹ = 共轭（单位四元数）
两个旋转合成：q = q₂ ⊗ q₁            // 顺序不能换，和矩阵一样
插值：slerp(q₀,q₁,t) = sin((1−t)Ω)/sinΩ · q₀ + sin(tΩ)/sinΩ · q₁
      Ω = acos(q₀·q₁)                // 两颗四元数的"夹角"
当前 q- |q|- 旋转角 θ- q₀ · q₁- 是否取了反号-
  1. 为什么是 θ/2：因为 q 作用一次是"转一半"，q v q⁻¹ 左右各乘一次才凑成 θ。 这个半角也是"转 2π 才回到 q 的相反数、4π 才回到 q"的来源。
  2. q 和 −q 表示同一个旋转。所以插值前必须统一符号：if (dot(q0,q1) < 0) q1 = -q1; 不做这一步，slerp 会带你走 360°−θ 的那条远路。取消勾选上面的"取反"就能看到轨迹绕一大圈。
  3. nlerp 其实够用：它不是匀速的，但偏差很小，实现便宜（一次 lerp + 一次 normalize）， 而且没有 sin/acos。动画系统里常用 nlerp 做过渡。slerp 只在需要严格匀速时用。
  4. 别自己转成欧拉角再插值。要读给 UI 看可以转欧拉角，但插值请留在四元数域里做。

3. 面试会问到的边界

  1. q₀·q₁ → 1（两个朝向几乎相同）时，sinΩ → 0，slerp 公式会除零 —— 必须退化成直接返回 q₀ 或用 nlerp。
  2. q₀·q₁ → −1 时同理，这也是"必须处理反号"的另一个原因。
  3. 四元数不能直接插值位置，位置还是线性 lerp；它只负责朝向。
  4. 多个骨骼的层级旋转，写成四元数乘法比矩阵省 3 个浮点，而且归一化能消除累积误差。
