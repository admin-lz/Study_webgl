CPU pick：鼠标反算成射线，JS 里求交

画面仍是 GPU 画的。拾取全程在 CPU：把鼠标变成世界空间射线，跟球 / AABB 求交，取最近的正 t。 黄点就是交点。对照：GPU pick。

1. 这条射线从哪来

鼠标像素 → NDC → 反投影 世界射线 JS 求交 最近 t
  1. 画布 CSS 坐标换成 NDC：x,y ∈ [−1, 1]，Y 要翻转。
  2. 用 (P·V)⁻¹ 把近平面、远平面两点变回世界坐标，连成射线。
  3. 球：二次方程。盒子：slab 法打 AABB。
  4. 留下最小正 t。遮挡要自己比距离，深度缓冲帮不了你。

交点是真 3D 点。网格一旦旋转 / 变形，就要改成三角形求交，CPU 会按三角形数量涨。

移动鼠标拾取 · 拖动旋转相机 · 黄点 = 射线交点

把鼠标移进画布。

2. 本页真正在跑的核心

const ndcX = (cssX / cssW) * 2 - 1;
const ndcY = 1 - (cssY / cssH) * 2;
const pNear = unproject(ndcX, ndcY, -1, invVP);
const pFar  = unproject(ndcX, ndcY,  1, invVP);
const dir = normalize(pFar - pNear);

// 每个物体：hitSphere 或 hitAABB，取最小正 t
let bestT = Infinity, best = null;
for (const obj of objects) {
  const t = obj.kind === "sphere"
    ? hitSphere(pNear, dir, obj.center, obj.radius)
    : hitAABB(pNear, dir, obj.center, obj.half);
  if (t > 0 && t < bestT) { bestT = t; best = obj; }
}
const hitP = pNear + dir * bestT;

地面没有参与求交，点到地上就是未击中。下一课用 GPU 再画一遍 ID 色，见 pick-gpu.html。

3. 对照着看

  1. 移到球体上：黄点应贴在球面上，提示里有 t 和交点坐标。
  2. 两个物体重叠时，t 更小的那个被选中——那就是离近平面更近的。
  3. 拖相机再拾取：射线随 V 变，交点仍应钉在物体表面。
  4. 点地面或空隙：未击中。CPU 不知道画面上「看起来」是什么，只知道几何。
