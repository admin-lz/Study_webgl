离屏渲染与后处理：先把画面画进纹理，再贴回屏幕

阴影图、GPU 拾取、镜子、泛光 —— 它们都靠同一个机制：FBO。 这一页先把场景渲染到一张纹理上，再用一个全屏三角形读它、加工它、贴回屏幕。 最后用模糊讲清可分离卷积为什么能省掉一个数量级。

1. 默认帧缓冲不是唯一选择

场景 → FBO 纹理 全屏 pass 读纹理 加工（模糊 / 边缘 / 阈值） → 屏幕
  1. 平时画进 null 帧缓冲，也就是 canvas。换成自己建的 FBO 就是画进纹理。
  2. FBO = 一组挂载点：颜色附件（纹理）+ 深度附件（renderbuffer 或纹理）。
  3. 建完必须 checkFramebufferStatus，不完整的话后面全是黑屏。
  4. 深度用 renderbuffer 就够 —— 我们不打算采样它，只要求它能参与深度测试。

离屏纹理的分辨率不必等于 canvas。 拉低一点就是性能换画质； 阴影图、half-res 后处理都是这么做的。

2. 全屏 pass 怎么写

  1. 不需要 VBO：顶点着色器直接用 gl_VertexID 生成一个盖住屏幕的大三角形。
  2. 为什么是三角形不是四边形：一个三角形没有对角线接缝，光栅化更省。
  3. 片元着色器把 UV 当输入，texture() 取离屏图，加工后输出。
  4. 这一趟要关掉深度测试和背面剔除 —— 它不参与 3D，只是一次 2D 图像运算。

后处理 pass 可以叠很多层。每多一层就多一次全屏读写， 带宽是这类效果的主要成本，所以能合并的 pass 就合并。

3. 可分离卷积为什么快

  1. 高斯核在二维上是可分离的：G(x,y) = G(x)·G(y)。
  2. 所以 N×N 的一趟可以拆成「横着扫一遍 + 竖着扫一遍」。
  3. 半径 r：单趟要 (2r+1)² 次采样，分离只要 2(2r+1) 次。
  4. r = 8 时是 289 次 vs 34 次，差 8.5 倍；r 越大差距越大。

代价是多一趟全屏读写，以及需要两张纹理轮换（ping-pong）—— 因为一趟不能同时读写同一张纹理。

4. 本页真正在跑的核心

// ① 建离屏目标：颜色挂纹理，深度挂 renderbuffer
const fbo = gl.createFramebuffer();
gl.bindFramebuffer(gl.FRAMEBUFFER, fbo);
gl.framebufferTexture2D(gl.FRAMEBUFFER, gl.COLOR_ATTACHMENT0, gl.TEXTURE_2D, tex, 0);
gl.framebufferRenderbuffer(gl.FRAMEBUFFER, gl.DEPTH_ATTACHMENT, gl.RENDERBUFFER, depthRb);
if (gl.checkFramebufferStatus(gl.FRAMEBUFFER) !== gl.FRAMEBUFFER_COMPLETE) fail(...);

// ② 第一趟：3D 场景画进离屏纹理（不是屏幕）
gl.bindFramebuffer(gl.FRAMEBUFFER, scene.fbo);
gl.viewport(0, 0, offW, offH);
gl.enable(gl.DEPTH_TEST);
drawScene();

// ③ 全屏 pass：读纹理 → 加工 → 贴回屏幕
gl.bindFramebuffer(gl.FRAMEBUFFER, null);
gl.viewport(0, 0, canvas.width, canvas.height);
gl.disable(gl.DEPTH_TEST);
gl.drawArrays(gl.TRIANGLES, 0, 3);   // 不需要 VBO，VS 用 gl_VertexID

// 顶点着色器：用 gl_VertexID 直接造一个盖住屏幕的三角形
vec2 p = vec2(float((gl_VertexID << 1) & 2), float(gl_VertexID & 2));
v_uv = p;
gl_Position = vec4(p * 2.0 - 1.0, 0.0, 1.0);

// ④ 可分离高斯：横一趟、竖一趟，中间用两张纹理轮换
blit(postA, bright, dir = vec2(1, 0));   // 横向
blit(postB, postA,  dir = vec2(0, 1));   // 纵向（读 postA 写 postB）

泛光是三步叠出来的：亮度阈值 → 模糊 → 和原图相加。 阈值必须在模糊之前，否则亮部会被邻域的暗像素稀释掉。

5. 对照着拧开关看

  1. 切「原图」：场景只过了一趟 FBO 就贴回来，和直接画几乎一样 —— 这是离屏渲染的最小形态。
  2. 切「高斯模糊」，在「可分离」和不可分离之间切换：画面一致，看采样数从 34 跳到 289。
  3. 把半径拉满 20：单趟要 1681 次采样，分离只要 82 次 —— 差距随半径平方增长。
  4. 离屏分辨率切到 0.25×：画面变糊、出现方块。这就是阴影图和 half-res 后处理的取舍。
  5. 切「Sobel 边缘」：只有 8 次采样，但输出的是梯度强度，不是颜色。
  6. 切「泛光」调阈值：调低 = 更多区域发光。注意阈值那一步必须排在模糊前面。
