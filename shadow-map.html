Shadow Mapping：从灯光画一张深度图，再比较远近

硬阴影。先从灯光看世界，把最近的深度存进纹理；再从相机画，把片元变到灯光空间，比一比「我比阴影图里记录的更远吗」。 更远 = 被挡住。软阴影见 PCSS。

1. 两趟绘制

灯光 VP 深度 FBO 相机 VP 比深度 乘进漫反射
  1. 灯光用正交投影（平行光）。阴影图上每个纹素 = 沿光线看到的最近深度。
  2. 片元世界坐标乘 lightVP，再从 NDC 映到 [0,1]，去采样那张深度图。
  3. 当前深度 − bias > 图上深度 → 在阴影里，漫反射打暗。
  4. bias 太小：地面自己挡住自己（acne）。太大：影子离物体（peter panning）。

阴影图分辨率有限，硬比较的边缘是锯齿。3×3 PCF 只是邻域平均，整圈一样糊，不是真正的半影。

右下角 = 灯光深度图

拖动旋转相机 · 黄球是灯 · 影子边缘发虚是纹素不够细

2. 本页真正在跑的核心

// ① 灯光视角，只写深度
bindFramebuffer(shadowFbo);
viewport(SHADOW_SIZE);
drawScene(u_mvp = lightVP * model);

// ② 相机视角，采样那张深度图
vec4 lp = u_lightVP * vec4(world, 1.0);
vec3 sc = lp.xyz / lp.w * 0.5 + 0.5;   // NDC → [0,1]
float closest = texture(u_shadow, sc.xy).r;
float shadow = (sc.z - bias > closest) ? 0.0 : 1.0;
color = ambient + diffuse * shadow;

阴影图不要开 MSAA，过滤用 NEAREST。深度比较不能线性插值出合法 ID，同样也不能插值出合法深度再硬比。

3. 对照着拧开关看

  1. bias 拉到 0：地面布满斑点，那就是 acne（自己和自己比深度，精度不够）。
  2. bias 拉很大：影子和物体脱开，那就是 peter panning。
  3. 勾上 3×3 PCF：边缘变软，但近处远处一样软。真正近实远虚见 pcss.html。
  4. 关掉「剔正面」再把 bias 调小：acne 更明显。背面深度更远，相当于白送一点偏移。
