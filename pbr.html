PBR：把"高光"拆成 D、G、F 三项

Blinn-Phong 的 pow(N·H, n) 只是个长得像高光的函数，参数没有物理含义、也不守恒能量。 PBR 换成 Cook-Torrance：微表面分布 D、几何遮蔽 G、菲涅尔 F， 再用 metalness / roughness 两个参数描述材质。

1. 公式的每一块在干什么

f_spec = D · G · F / (4 · (N·L) · (N·V))
L_o = (k_d · albedo / π + f_spec) · L_i · (N·L)

D  GGX：ndf = a² / (π ((N·H)²(a²-1)+1)²)     ← 微表面朝向 H 的比例，a = roughness²
G  Smith：遮蔽（微表面互相挡住），roughness 越大衰减越多
F  Schlick：F0 + (1-F0)(1 - V·H)⁵              ← 掠射角反射率必然趋近 1
k_d = (1 - F)(1 - metalness)                  ← 剩下的能量才轮到漫反射
  1. F0 是垂直入射的反射率：绝缘体约 0.04（水 0.02、钻石 0.17），金属则用基础色当 F0。
  2. metalness 不是"有多亮"，而是"这是不是金属"：金属没有漫反射，能量全走镜面。
  3. roughness 只影响 D 的尖锐程度，也就是高光多大、多糊。注意 a = roughness² 是约定俗成的重映射。
  4. 分母的 4(N·L)(N·V) 来自微表面模型的立体角变换 —— 少了它，掠射角会出现能量爆掉的白边。

2. 为什么必须做色调映射

  1. PBR 计算的是线性 HDR 辐射度，可以远大于 1。直接写进 8 位缓冲区会被粗暴截断成一片死白。
  2. Reinhard：x/(1+x)，便宜但高光发灰。ACES 曲线更接近胶片，是目前的主流默认。
  3. 色调映射之后还要做 sRGB 编码（pow(c, 1/2.2)），否则暗部会糊成一团。
  4. 顺序不能反：线性光照 → 色调映射 → gamma 编码。贴图进来的时候则要先去 gamma。

这一页故意把三个开关都露出来：关掉色调映射能看到高光直接"撞顶"，关掉 gamma 能看到整体发暗、对比过硬。

3. 环境光：IBL 在替我们算什么

  1. 点光源只能照亮"正好朝着光源"的方向。真实环境里光从四面八方来，这部分由 IBL 提供。
  2. 漫反射环境光 = 对半球做积分（irradiance）→ 结果非常低频，可以用一张很糊的立方体贴图代替。
  3. 镜面环境光 = 按 roughness 做预过滤（PMREM），roughness 越大用越糊的一层。
  4. 本页为了不依赖贴图，用一个解析的"天空 + 地面 + 太阳"函数来近似，太阳的高光指数随 roughness 变钝。

面试常问："为什么 IBL 的漫反射和镜面反射要用不同的预计算？" 因为漫反射的积分核是 cosθ，镜面反射的积分核是随 roughness 变化的 NDF —— 卷积核不同，结果就不能共用一张图。
