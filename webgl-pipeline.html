WebGL2 流程：从画一个三角形写起

每次画一帧，JS 只做两件事：把数据交给 GPU，然后 下令 draw。 真正画像素的是 GPU 固定管线。下面右侧就是最小可运行程序：3 个顶点 → 1 个三角形。

1. 每帧在 GPU 里怎么走

顶点缓冲 VBO → 顶点着色器 → 图元组装 → 光栅化 → 片元着色器 → 深度 / 混合 → 画布像素
  1. 顶点着色器：每个顶点跑一次。输入 a_pos，输出必须写 gl_Position（裁剪空间 -1~1）。
  2. 图元组装：3 个顶点收成一个 TRIANGLES。
  3. 光栅化：三角形覆盖了哪些像素，就生成哪些片元。
  4. 片元着色器：每个片元跑一次，写出 outColor。

三角形阶段还没有相机、没有纹理。顶点直接写在裁剪空间里，所以看不见矩阵。

2. JS 必须按这个顺序写

  1. 拿 canvas.getContext("webgl2")。
  2. 写两段 GLSL：顶点着色器 + 片元着色器。
  3. createShader → compileShader → createProgram → attach → link。
  4. CPU 上准备 Float32Array 顶点。
  5. createBuffer + bufferData 把数组上传到 GPU（VBO）。
  6. WebGL2 用 VAO 记住「哪个 attribute 怎么从 buffer 取数」。
  7. clear + drawArrays(TRIANGLES, 0, 3)。

后面加颜色、旋转、贴图、相机，都是在第 4～7 步上插东西，顺序不变。

裁剪空间：中心 (0,0)，右 +X，上 +Y。三个点已经写死在数组里。

3. 三角形：整份最小代码（本页正在跑的就是它）

// ① 上下文
const gl = canvas.getContext("webgl2");

// ② 着色器源码（GPU 程序，不是 JS）
const VS = `#version 300 es
in vec2 a_pos;
void main() {
  gl_Position = vec4(a_pos, 0.0, 1.0);
}`;
const FS = `#version 300 es
precision mediump float;
out vec4 outColor;
void main() {
  outColor = vec4(0.2, 0.7, 1.0, 1.0);
}`;

// ③ 编译 + 链接成 program
const prog = link(gl, VS, FS);
gl.useProgram(prog);

// ④ CPU 顶点：上、左下、右下
const data = new Float32Array([
   0.0,  0.6,
  -0.6, -0.5,
   0.6, -0.5,
]);

// ⑤ VBO：把数组拷到 GPU
const vbo = gl.createBuffer();
gl.bindBuffer(gl.ARRAY_BUFFER, vbo);
gl.bufferData(gl.ARRAY_BUFFER, data, gl.STATIC_DRAW);

// ⑥ VAO：声明 a_pos = 每顶点 2 个 float
const vao = gl.createVertexArray();
gl.bindVertexArray(vao);
const loc = gl.getAttribLocation(prog, "a_pos");
gl.enableVertexAttribArray(loc);
gl.vertexAttribPointer(loc, 2, gl.FLOAT, false, 0, 0);

// ⑦ 画一帧
gl.viewport(0, 0, canvas.width, canvas.height);
gl.clearColor(0.08, 0.08, 0.12, 1);
gl.clear(gl.COLOR_BUFFER_BIT);
gl.drawArrays(gl.TRIANGLES, 0, 3);
