PCSS：同一张阴影图，按半影宽度改 PCF 半径

阴影图还是 Shadow Mapping 那一张。PCSS 多两步：先在邻域里找挡住光线的平均深度（blocker）， 再用相似三角形估半影宽度，接触处核小、远离后核大。

1. 三步

阴影图 搜 blocker 估 penumbra 变半径 PCF
  1. 灯光当成有面积的盘。面积越大，半影越宽。
  2. 在 lightSize 对应的 UV 邻域里，把比接收点更近的深度取平均 → 挡光平面。
  3. 相似三角形：penumbra = (z接收 − z挡) / z挡 × lightSize。
  4. 用这个宽度做泊松盘 PCF。没有 blocker 就是全亮。

固定 3×3 PCF 不管远近都糊一圈。PCSS 的软是「灯有大小」推出来的，贴着物体的影子仍然实。

2. 本页真正在跑的核心

float lightUV = lightSize / orthoWidth;          // 灯在阴影图上占多少 UV

// ① 搜挡光点
for Poisson 样本 in 半径 lightUV:
  if (mapDepth < zReceiver - bias) 累加，计入 blocker

// ② 半影宽度（相似三角形）
penumbra = (zReceiver - avgBlocker) / avgBlocker * lightUV;

// ③ 用 penumbra 当 PCF 半径
visibility = 泊松盘里「没被挡住」的比例;

阴影图本身没变，变的是怎么采样。灯面积拉大，只有半影变宽，本影（全黑心）还在。切到「硬阴影」对照 shadow-map.html。

3. 对照着拧开关看

  1. PCSS + 灯面积拉大：柱脚附近仍然实，影子尾巴变糊。
  2. 切「固定 PCF」：整圈一样软，贴地也不实。
  3. 切「硬阴影」：边缘锯齿，没有半影。
  4. 灯面积拉到最小：PCSS 接近硬阴影。面积是这个算法里唯一的「软」来源。
