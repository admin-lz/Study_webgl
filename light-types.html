光源类型与衰减：为什么点光源必须有个"范围"

平行光没有位置、点光源按距离衰减、聚光灯再加一层角度锥 —— 三种光源的区别其实只有两件事： 光的方向怎么来、强度怎么随距离和角度掉。这一页把衰减曲线单独拎出来调。

1. 三种光源，三个方向公式

平行光：L = -lightDir                        （不衰减，太阳）
点光源：L = normalize(lightPos - p)          × att(dist)
聚光灯：L = normalize(lightPos - p)          × att(dist) × spot(cosθ)
半球光：无方向，直接按 N.y 在天空色/地面色之间插值（环境光的廉价近似）

平行光其实是"距离无穷远的点光源"：方向处处相同，所以没有距离项。 它还有个好处是光照与位置无关，可以在顶点着色器里算，也可以直接预热进法线。

2. 衰减怎么写

// 物理：平方反比。距离趋近 0 时会爆到无穷大，必须 clamp
att = 1.0 / max(dist * dist, eps);

// 工程：加一个"影响半径"，超出就彻底归零 —— 这样才能做光源剔除
float f = clamp(1.0 - pow(dist / range, 4.0), 0.0, 1.0);
att = f * f / (dist * dist + 1.0);

// 美术：线性/恒定衰减，好调但不物理
att = clamp(1.0 - dist / range, 0.0, 1.0);
  1. 纯 1/d² 的问题不是亮度，而是永远不为零 —— 一盏灯会影响场景里的每个像素。
  2. 有了 range 截断，才能把光源分桶（Forward+ / Clustered），这是现代引擎能跑几百盏灯的前提。
  3. 把衰减从"固定曲线"换成 1/d² 时，画面会整体变暗：同一盏灯在同样的距离上亮度变了。所以强度必须跟着重算，别以为是 bug。

3. 聚光灯的锥

float cd = dot(-L, spotDir);                  // cosθ
float inner = cos(angle * (1.0 - penumbra));  // 内锥：完全亮
float outer = cos(angle);                     // 外锥：完全暗
float spot = smoothstep(outer, inner, cd);    // 中间平滑过渡

注意 smoothstep(outer, inner, ...) 里 outer < inner： 角度越大 cos 越小，所以"外锥"对应更小的 cos 值。写反了不会报错，只会得到一圈硬边或者完全没光。 半影 = 1 时内外锥重合，等于硬边；半影 = 0 时整个锥体都是渐变，没有明确边界。
