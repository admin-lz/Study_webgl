碰撞检测：球 / AABB 有没有叠在一起

和 CPU pick 用同一套几何。拾取问的是「这条射线打中谁」； 碰撞问的是「这两个物体现在叠了没有」。都在 JS 里算，GPU 只负责把结果画出来。 黄线是把它们推开的方向（MTV）。

1. 三种测试

积分位移 → 房间边界 两两检测 MTV 推开 弹速度
  1. 球–球：中心距 < r₁+r₂。法线就是两心连线。
  2. AABB–AABB：三个轴的投影都重叠。重叠最短的那一轴就是分离方向。
  3. 球–AABB：球心到盒子的最近点，距离 < 半径。球心在盒子里时，沿最近的面推出去。

检测到的不只是 true/false，还有重叠量 overlap 和单位法线 n（从 A 指向 B）。 沿着 n 各退一半，叠在一起的物体就会分开。

点物体拖动 · 点空处旋转相机 · 碰撞的物体会发红，黄线 = 推开方向

等待第一帧。

2. 本页真正在跑的核心

// 球–球
const d = b.center - a.center;
const dist = length(d);
const overlap = a.radius + b.radius - dist;
if (overlap > 0) n = d / dist;

// AABB–AABB：取重叠最短的轴
const ox = (a.hx+b.hx) - abs(b.x - a.x);  // y、z 同理
if (ox>0 && oy>0 && oz>0) n 落在 min(ox,oy,oz) 那一轴

// 球–AABB：最近点
q = clamp(sphere.center, box.min, box.max);
if (length(sphere.center - q) < sphere.radius) 碰撞

// 推开（n 从 A 指向 B）
a.center -= n * overlap * 0.5;
b.center += n * overlap * 0.5;

关掉「分离重叠」，它们会穿过去，但仍然发红——那就是「只检测、不响应」。房间墙壁用同一套 AABB 夹紧。

3. 对照着拧开关看

  1. 默认会弹来弹去。发红的一对，黄线指向重叠最短的方向。
  2. 关掉「分离重叠」：物体互相穿过，一直红着。检测还在，只是没推开。
  3. 只关「弹性碰撞」：分开但不换速度，最后会挤成一堆慢慢滑开。
  4. 拖一个球去撞立方体：走的是球–AABB。点空处才能转相机。
  5. 暂停后再拖：纯看重叠，方便对公式。
