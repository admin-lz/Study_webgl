GPU pick：离屏平涂 ID 色，readPixels 读 1 个像素

不在 JS 里求交。用同一套 MVP 把每个物体涂成独一无二的 ID 色，深度测试决定谁留在像素上，再 readPixels 还原 id。 对照：CPU pick。

1. ID 缓冲怎么来

同一套 MVP → 离屏 FBO 每物体一种 ID 色 深度测试 readPixels 1px
  1. FBO 里关掉光照、关掉抗锯齿。片元只输出 id → RGB。
  2. 深度照常开：谁离相机近，谁的 ID 留在那个像素上。
  3. readPixels 读鼠标那 1 个像素，把 RGB 还原成整数 id。
  4. 清成黑色 = id 0 = 背景。本页：id = R + G·256 + B·65536。

结果和屏幕像素一致，复杂网格也一样快。代价是多一次 draw，以及 readPixels 会让 GPU 和 CPU 同步。没有 3D 交点。

右下角 = ID 缓冲

移动鼠标拾取 · 拖动旋转相机 · 地面没有 ID

把鼠标移进画布。

2. 本页真正在跑的核心

bindFramebuffer(pickFbo);
clear; // 黑 = id 0
drawEachObject(idColor);   // 无光照，有深度

// GPU Y 在左下，鼠标 Y 在左上，必须翻转
const px = floor(cssX * canvas.width  / cssW);
const py = canvas.height - 1 - floor(cssY * canvas.height / cssH);
readPixels(px, py, 1, 1, RGBA, UNSIGNED_BYTE, pixel);
const id = pixel[0] + pixel[1] * 256 + pixel[2] * 65536;

ID 缓冲不要开 MSAA：抗锯齿会把相邻 ID 混成非法颜色。 上一课射线求交见 pick-cpu.html。

3. 对照着拧开关看

  1. 勾上「显示 ID 缓冲」：右下角每种色对应一个可点物体，地面是黑的。
  2. 关掉「pick 开深度」：后画的物体会盖住前面的 ID，和没深度的绘制一样。
  3. 提示里的 rgb 就是刚读到的那一个像素。id 1 的红球是 (1,0,0)。
  4. 没有黄点：GPU pick 只拿到颜色，不算出 3D 交点。
