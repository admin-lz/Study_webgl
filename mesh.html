索引、绕序与背面剔除：同一份网格，顶点数差近 6 倍

drawArrays 是每个三角形各写 3 个顶点，drawElements 是顶点只存一份、用索引拼三角形。 顺便把 绕序 和 背面剔除 一起讲完 —— 它们和索引是同一件事的两面：都在问「这个顶点/这个面，究竟是谁」。

1. 索引缓冲省的是什么

顶点表（唯一） 索引表 → 图元组装 → 三角形
  1. 一个开口圆筒：48 × 24 个格子、圆周 48 段、高度 25 圈顶点。
  2. 不共享顶点：2304 个三角形 × 3 = 6912 个顶点，位置和法线要重复写近 6 遍。
  3. 共享顶点：每格只需要一份属性，1200 个顶点 + 6912 个索引。
  4. 索引是 2 字节整数，比一整套 vec3 pos + vec3 normal（24 字节）便宜得多。

这里选开口圆筒（没有顶盖和底盖）不是偷懒：从斜上方看进去， 内壁那一整面在几何上就是背面，正好用来演示剔除和绕序。

但不是所有顶点都能共享。 立方体只有 8 个角，却不能只用 8 个顶点 —— 三个面共用同一个角，但每个面的法线不同。要共享就得给角点三种法线， 所以立方体实际是 24 个顶点（每面 4 个）。索引只在顶点属性完全一致时才省得下来。

2. 绕序决定谁是正面

  1. 光栅化之后，GPU 按屏幕坐标算三角形的有向面积（或等价地看叉积符号）。
  2. 正负号来自顶点顺序：顺时针 / 逆时针。默认 frontFace(CCW)，逆时针算正面。
  3. enable(CULL_FACE) + cullFace(BACK) 就是把背面的三角形整个跳过。
  4. 片元着色器里可以用 gl_FrontFacing 知道当前片元属于哪一面。

绕序错了不会报错，只会剔掉该留的、留下该剔的，看起来像「模型里外翻过来了」。 这是最常见的自建网格 bug。

3. 什么时候不能剔除

  1. 单面几何：树叶、旗帜、布片只有一个面，剔了就从背面消失。
  2. 开放几何：没有封口的圆筒、盒子，需要看见内壁（这一页的圆筒就是）。
  3. 透明或不封闭：玻璃面板两面都要画。

标准做法是双面材质：在片元里对背面把法线取反（N = gl_FrontFacing ? N : -N）， 光照才对，而不是简单地把剔除关掉了事。

4. 本页真正在跑的核心

// ① 顶点表 + 索引表（开口圆筒，法线是径向解析式，所以接缝处能共用顶点）
const vertexCount = N * (M + 1);        // 48 × 25 = 1200
const indexCount  = N * M * 6;          // 每格 2 个三角形

const a = i * V + j,                    b = ((i+1) % N) * V + j;
const c = ((i+1) % N) * V + (j+1),      d = i * V + (j+1);
indices.push(a, d, c,  a, c, b);   // 这个顺序的叉积朝外 → 逆时针 → 正面

// ② 两个 VAO：一个走索引，一个把索引在 CPU 上展开
gl.bindVertexArray(indexedVao);
gl.drawElements(gl.TRIANGLES, indexCount, gl.UNSIGNED_SHORT, 0);  // 提交 1200 个顶点

gl.bindVertexArray(expandedVao);
gl.drawArrays(gl.TRIANGLES, 0, indexCount);                       // 提交 6912 个顶点

// ③ 绕序和剔除
gl.frontFace(ccw ? gl.CCW : gl.CW);
if (culling) { gl.enable(gl.CULL_FACE); gl.cullFace(gl.BACK); }
else gl.disable(gl.CULL_FACE);

// ④ 双面材质靠 gl_FrontFacing
vec3 N = normalize(v_normal);
if (!gl_FrontFacing) N = -N;    // 背面把法线翻过来，光照才对

两种绘制方式画面完全一样，差别只在 GPU 要多读几遍顶点。 顶点着色器是每顶点跑一次的，所以省顶点就是省顶点着色器的调用次数。

5. 对照着拧开关看

  1. 切换「绘制方式」：画面不变，看 提交顶点数 从 1200 跳到 6912。
  2. 关掉「背面剔除」：从上面看进筒里，内壁露出来，被染成洋红。
  3. 开着剔除，把「绕序」切成 CW：里面和外面整个对调 —— 现在留下的是内壁。这就是绕序写反的后果。
  4. 关掉「背面染洋红」再翻转绕序：表面变成纯色但光照不对，这正是「绕序错了但不报错」的隐蔽之处。
  5. 勾上「显示法线」：确认法线全都朝外。如果法线朝里，说明顶点表本身算错了。
