立方体贴图：用一个方向去查环境

天空盒、反射、折射、IBL 的底子都是同一件事：给 samplerCube 一个方向向量， 它自己算出落在哪个面、面的哪个位置。这一页把 6 个面摊开摆出来，让你看清方向是怎么落到面上的。

1. 为什么是"方向"而不是 UV

  1. 2D 贴图用 (u, v) 定位，所以你得先知道"在哪儿"—— 球面上要自己算经纬度。
  2. 立方体贴图用 vec3 定位：取绝对值最大的那个分量决定面，剩下两个分量除以它得到面内坐标。
  3. 因为按轴向切分，相邻面的边界是接得上的，没有极点、也没有接缝（WebGL2 的立方体贴图还默认开启 seamless 过滤）。
  4. 代价是分辨率被均分到 6 个面上，而且同一方向的精度在不同面上并不一致。
面      sc      tc
+X     -rz     -ry
-X     +rz     -ry
+Y     +rx     +rz
-Y     +rx     -rz
+Z     +rx     -ry
-Z     -rx     -ry
s = (sc/|ma| + 1)/2   t = (tc/|ma| + 1)/2

记住这张表的实际意义：+X 面的"上"是 +Y，"右"是 −Z。 用错了不会报错，只会让天空盒里的太阳跑到反方向 —— 这类 bug 只能靠"看起来对不对"来抓。

2. 上传：一个面一次 texImage2D

gl.bindTexture(gl.TEXTURE_CUBE_MAP, env);
for (let i = 0; i < 6; i++) {
  gl.texImage2D(gl.TEXTURE_CUBE_MAP_POSITIVE_X + i, 0,
                gl.RGBA, s, s, 0, gl.RGBA, gl.UNSIGNED_BYTE, faces[i]);
}
gl.generateMipmap(gl.TEXTURE_CUBE_MAP);   // 立方体贴图同样能生成 mip 链

采样器类型必须匹配：shader 里声明 samplerCube，就必须绑到 TEXTURE_CUBE_MAP； 绑成 TEXTURE_2D 会让 draw 直接报 INVALID_OPERATION， 而且错误信息通常不会告诉你是哪张纹理。

3. 从反射到 IBL

  1. 天空盒：把立方体放在相机中心（只保留视图矩阵的旋转部分），采样方向就是顶点方向。为了永远不被别的物体挡住，gl_Position 写成 p.xyww，把 z 顶到远平面。
  2. 反射：reflect(-V, N) 得到镜像方向，拿它查环境 → 镜面反射。
  3. 粗糙度：直接 textureLod(env, dir, lod)，用更糊的一层当"大概的环境"。真正的 PBR 会用预过滤的多级立方体贴图（PMREM）把这一步离线做掉。
  4. 漫反射环境光：用最糊的那一层按法线方向采样，就近似了半球积分（irradiance）。

注意 mip 链在这里不只是抗锯齿：它被当成"预先算好的模糊程度"来用， 这就是为什么 IBL 的预过滤要专门设计滤波核，而不是随手 generateMipmap。
